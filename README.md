## 👋 About

- 📱 **Swift / iOS**로 앱을 만들고, **TypeScript**로 웹·서버·MCP 서버를 만듭니다. App Store 출시작 3종과 토스 미니앱 1종을 운영 중입니다.
- 🤖 요즘은 **Claude Code 스킬·훅·MCP** 같은 AI 에이전트 워크플로우 도구에 집중하고 있습니다.
- 🧪 매일 작은 실험을 하나씩 만들어 공개 저장소에 남깁니다.
